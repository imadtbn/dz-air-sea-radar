# DZ Air & Sea Radar — الرادار الجزائري للملاحة الجوية والبحرية

منصة عربية RTL متجاوبة لاكتشاف المطارات والموانئ الجزائرية، وعرض الطائرات المرصودة (إذا أتاح مصدر البيانات الاتصال) ومعلومات الرصد البحري المشروطة بتفعيل مستقبل AIS خارجي.

**الحالة الفعلية في 16 أكتوبر 2026:**
- خرائط MapLibre + OpenFreeMap: اختُبرت بالمتصفح السحابي بعرض هاتف (390px) وحاسوب (1440px)، وتم تحميل طبقة الخريطة بنجاح.
- الطائرات: مسار ADS-B المباشر يعرض خطأ عدم الإتاحة في المتصفحين. وسيط Cloudflare منشور مع `UPSTREAM_ALLOWED=false` انتظارًا لموافقة التشغيل العام من ADSB.lol؛ لا توجد بيانات طائرات حية مؤكدة.
- METAR: نجح اختبار API الفعلي للمطار DAAG وأعاد تقريرًا حقيقيًا من Aviation Weather Center؛ توفر تقارير المطارات الأخرى يختلف.
- السفن: مستقبل Node.js عبر AISStream والطبقة على الموقع موجودان ككود فقط، لكن الخدمة غير مفعلة ولا توجد بيانات بث بحري فعلية (يلزم مفتاح خاص وخادم دائم).
- PWA والمفضلة والمشاركة: أضيفت الملفات والواجهات؛ اختبار التثبيت على هاتف فعلي لا يزال مطلوبًا.
- **هذه المنصة ليست نظام ملاحة أو سلامة معتمدًا.**

## هيكل النظام

- `assets/js/radar.js`: MapLibre ولوحة الطائرات في المتصفح، تحديث محافظ؛ لا بيانات تجريبية.
- `assets/js/places.js`: مواقع مرجعية ثابتة؛ ليست مواقع طائرات أو سفن.
- `assets/js/marine.js`: واجهة AIS تقرأ snapshot من مصدر HTTPS عند تهيئته.
- `assets/js/marine-config.js`: عنوان وسيط السفن؛ فارغ حتى إعداد الخادم المصرح به.
- `assets/js/air-config.js`: عنوان وسيط الطائرات؛ فارغ حتى الحصول على الموافقة.
- `assets/js/weather.js`: واجهة METAR للمطارات المدرجة.
- `worker/worker.js`: Cloudflare Worker للتخزين المؤقت ومعلومات الطقس وADS-B عند التصريح.
- `marine-relay/server.mjs`: مستقبل WebSocket دائم يعيد الاتصال ويحتفظ بآخر الرصد لمدة 15 دقيقة.
- `manifest.webmanifest`, `sw.js`: دعم PWA؛ التخزين المحلي مخصص للملفات الثابتة وليس لنتائج ADS-B/AIS.
- `tests/site.test.mjs`: فحوص Node.js للمسارات والحماية.

## التشغيل والاختبار

يتطلب خادم HTML المحلي Node.js 20+ أو Python:

```sh
python3 -m http.server 8080
# افتح http://localhost:8080/
npm test
```

ينبغي تشغيل فحوص الهاتف والحاسوب أيضًا على:
- عرض 390 × 844: القائمة الرئيسية، عرض الخريطة، المفضلة، بطاقة METAR، ملء الشاشة.
- عرض 1440 × 900: الخريطة، التحكم، القوائم، عدم تداخل الهيدر أو الأدوات.
- اختبار فتح `/health` ثم `/api/metar?icao=DAAG` من Worker.
- التحقق من عدم ظهور مواقع قديمة عندما يفشل طلب ADS-B/AIS.

## تفعيل التتبع عندما تكون الشروط متوفرة

**ADS-B:** يرجى مراجعة [شروط ADSB.lol](https://api.adsb.lol/docs) والحصول على تأكيد لاستخدام الإنتاج (وبيانات ODbL 1.0). بعد الموافقة أعد نشر Worker بقيمة `UPSTREAM_ALLOWED=true` وعيّن عنوان Worker في `assets/js/air-config.js`. يجب اختبار التحمل وقيود التحديث وحماية الإساءة قبل الإعلان عن توفر البيانات.

**AIS:** أنشئ حساب [AISStream](https://www.aisstream.io/documentation/) وتحقق من سماح إعادة العرض، ثم ضع `AISSTREAM_API_KEY` في متغير بيئة سري لدى خادم Node.js دائم. لا تضع المفتاح في GitHub أو داخل JavaScript للواجهة. انشر الخادم خلف HTTPS، ثم حدّد عنوان `/api/vessels` في `assets/js/marine-config.js`. يتطلب استخدامًا فعليًا لتغطية الساحل واختبار إعادة الاتصال وتأخر البيانات.

**طقس المطارات:** يستخدم Aviation Weather Center API؛ CORS المباشر محظور من المصدر، لذا يمر عبر Worker ويُخزّن مؤقتًا لمدة 10 دقائق لمجموعة رموز ICAO محدودة.

## مصادر البيانات والإسناد

- [ADSB.lol](https://www.adsb.lol/docs/open-data/api/) — ODbL 1.0؛ متطلبات النشر الإنتاجي وفق المزود.
- [AISStream](https://www.aisstream.io/documentation/) — بث AIS يتطلب مفتاحًا خاصًا وخادمًا.
- [Aviation Weather Center](https://aviationweather.gov/data/api/) — METAR؛ بحد مصدر 100 طلب في الدقيقة.
- [OurAirports](https://ourairports.com/data/) — بيانات مطارات مرجعية.
- [OpenFreeMap](https://openfreemap.org/) و[MapLibre](https://maplibre.org/) — خريطة الأساس.

## تصحيح ربط الرادار الجوي

تم ربط الواجهة افتراضيًا بالوسيط المنشور `dz-air-sea-aircraft-api.imadtbn-prayer.workers.dev` بدلاً من استدعاء `api.adsb.lol` من كل متصفح. يبدأ الوسيط بالقيمة `UPSTREAM_ALLOWED=false` فلا يقدم بيانات حية أو يستدعي المصدر حتى الإذن. يعرض الموقع سبب الحجب عند رد `503 UPSTREAM_NOT_AUTHORIZED`، ويعمل تلقائيًا عبر التخزين المؤقت بعد تفعيل المصدر قانونيًا واختبار الخدمة. الطلبات غير المرخصة ليست قابلة للتجاوز من العميل.


## اختيار مزوّدَي بيانات الطائرات (أكتوبر 2026)

**الأساسي:** [ADSB.lol](https://api.adsb.lol/docs)؛ API مجاني بترخيص **ODbL 1.0**. الوثائق تطلب التواصل مع مشغّل الخدمة قبل الاعتماد الإنتاجي. قد تُفرض مفاتيح API للمساهمين مستقبلًا.

**الاحتياطي:** [adsb.fi OpenData](https://github.com/adsbfi/opendata/blob/main/README.md)؛ API مجاني للاستخدام **الشخصي غير التجاري** ويشترط ذكر المصدر، وبحد منشور **طلب واحد/ثانية**. نشر موقع مفتوح للزوار أو إعادة بثه ليس مساويًا تلقائيًا للاستخدام الشخصي؛ لذلك يتطلب موافقة/توضيحًا من المشغل قبل تفعيل الاحتياطي.

تم تطبيق التوجيه عبر Cloudflare Worker مع:
- مصدر ADSB.lol أولًا عبر `/v2/lat/.../lon/.../dist/250`؛ وعند عطل 5xx أو 429 أو انتهاء المهلة يمكن الرجوع إلى `adsb.fi /api/v3/lat/.../lon/.../dist/250`، شرط تفعيل المصدر الاحتياطي بشكل مستقل.
- لا يُستخدم المصدر البديل لتجاوز 401/403/400 أو شروط الترخيص.
- متغيرا إعداد **مستقلان، معطلان افتراضيًا**: `UPSTREAM_ALLOWED=false` و`ADSBFI_ALLOWED=false`. لا يكفي وصف الموقع بأنه غير ربحي للالتفاف على شروط الاستخدام.
- تخزين مؤقت لمدة دقيقة عبر Cache API المحلي لمواقع Cloudflare الحافة؛ مع تجميع الإحداثيات لأقرب 0.25 درجة. لا يُضمن تخزين موحّد عالميًا بين مراكز البيانات ولا منع كل الطلبات المتزامنة.
- لا توجد طلبات إلى المصدرين مباشرة من JavaScript المتصفح؛ المصدر المعلن ووقت الرصد ونطاق 250 ميلًا بحريًا يظهران في واجهة المستخدم عند توفر بيانات مصرّح بها.
- حساب عمر الموقع مع فارق زمن التخزين المؤقت واستبعاد الطائرات التي يتجاوز عمر بياناتها 120 ثانية.
- لا توجد بيانات وهمية أو إعادة عرض لرصد قديم عند فشل جلب البيانات.

**خطة التشغيل:** بعد تأكيد السماح بإعادة العرض العلني مع كل مزوّد، أعد نشر `worker/worker.js` بمتغير التفعيل المناسب، ثم افتح `diagnostics.html` للاختبار. يتطلب التشغيل الفعلي مراجعة إسناد البيانات والخصوصية والحدود الزمنية والأداء وحماية الإساءة.
