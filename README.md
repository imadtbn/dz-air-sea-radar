# DZ Air & Sea Radar — الرادار الجزائري للملاحة الجوية والبحرية

منصة عربية متجاوبة لاستكشاف المطارات والموانئ الجزائرية على خريطة تفاعلية عالمية، تمهيدًا لدمج بيانات الرصد الجوي والبحري.

**الحالة:** المرحلة الأولى (الهوية والخرائط) — لا تتضمن هذه النسخة تتبعًا مباشرًا للطائرات أو السفن. جميع المؤشرات الحالية تمثل مواقع مرجعية ثابتة.

## الصفحات

- \`index.html\`: الرئيسية والخريطة التفاعلية، البحث عن المواقع، التصفية الجوية والبحرية، زر الجزائر/العالم، التكبير والتصغير، محاولة تحديد الموقع عند الطلب، وضع ملء الشاشة.
- \`airports.html\`: دليل المطارات مع البحث برمز المطار أو اسمه أو الولاية.
- \`ports.html\`: دليل الموانئ مع البحث وروابط الانتقال للخريطة.
- \`about.html\`: تعريف المشروع والمراحل الست والتنبيهات.

## التقنيات

HTML5 وCSS3 وJavaScript وحدات ES Modules دون أداة بناء.
- [MapLibre GL JS](https://maplibre.org/) 6.13.0 — مكتبة الخريطة عبر CDN.
- [OpenFreeMap](https://openfreemap.org/quick_start/) — خريطة الأساس (Liberty).
- [OurAirports](https://ourairports.com/data/) — المرجع الأساسي لبيانات وإحداثيات المطارات.
- [GeoNames](https://www.geonames.org/) ومراجع جغرافية عامة — إحداثيات مرجعية للموانئ.

الخرائط تتطلب اتصالًا بالإنترنت وWebGL. لا توجد مفاتيح API أو بيانات دخول مكشوفة في الواجهة.

## اختبارات المرحلة الأولى

1. التنقل الرئيسي على الحاسوب وفتح/إغلاق القائمة على الهاتف مع لوحة المفاتيح.
2. تحميل الخريطة وتحريكها وتكبيرها دون قفز الهيدر.
3. أزرار الجزائر والعالم وإظهار المطارات/الموانئ/الكل.
4. البحث عن «الجزائر» أو «وهران» و\`ALG\` و\`DZORN\` في القائمة والأدلة.
5. الانتقال من بطاقة الدليل إلى الخريطة مع التركيز على الموقع المحدد.
6. الضغط على «موقعي» والتحقق من تعامل الواجهة مع الرفض أو السماح.
7. ملء الشاشة ثم الخروج منها، وتجربة عرض 320 / 375 / 768 / 1440 بكسل.
8. عدم وجود أي بيانات حية مزيفة أو أرقام لحركة الطائرات والسفن.

## المراحل التالية

2. الرادار الجوي عبر ADS-B وفق التراخيص وحصص الطلبات.
3. الرادار البحري عبر AIS مع مستقبل خلفي ومراعاة التغطية.
4. المطارات والموانئ والأرصاد.
5. المفضلة والبحث والإحصاءات والسجل حسب ما تسمح به المصادر.
6. PWA والسيو المتقدم وتحسين الأداء والاختبارات النهائية.

## حدود البيانات والسلامة

- إحداثيات الموانئ مواقع **تقريبية** لتسهيل الاستكشاف، وليست إحداثيات أرصفة أو نقاط ملاحة رسمية.
- الإحداثيات والرموز الجوية مأخوذة من بيانات مفتوحة؛ تحقق من المصدر الرسمي عند الحاجة.
- لا يجوز استخدام الموقع للملاحة الجوية/البحرية التشغيلية أو اتخاذ قرارات تتعلق بالسلامة.
- لن يضاف بث مباشر حتى يتم التحقق من الترخيص والتغطية ومعدلات التحديث.


## المرحلة الثانية — الرصد الجوي التجريبي

- يعتمد على ADSB.lol ضمن دائرة 250 ميلًا بحريًا حول مركز الخريطة، مع تحديث لا يزيد عن مرة في الدقيقة لكل زائر.
- بيانات السرعة: knots إلى كم/سا، الارتفاع: قدم إلى متر، الاتجاه: درجات، وآخر رصد: ثوانٍ.
- لا تظهر طائرات بلا مواقع صالحة أو يتجاوز عمر رصدها دقيقتين. يُمسح العرض عند انقطاع الخدمة، دون بيانات تجريبية مصطنعة.
- يتطلب الاتصال من المتصفح السماح بـ CORS من الجهة المزودة. إذا حُظر الاتصال ستظهر رسالة خطأ بدل أرقام وهمية.
- لم يتم نشر أي Cloudflare Worker؛ ينبغي إعداد وسيط مرخص ومخبأ قبل التوسع في النشر وتأكيد الموافقة الإنتاجية للمصدر.


## API proxy readiness / اختبارات الاستخدام العام

تمت إضافة `worker/worker.js` كوسيط Cloudflare *مجهز وغير منشور* ومغلق افتراضيًا ريثما تتحقق موافقة المزود على استخدام الإنتاج. لا تضبط `UPSTREAM_ALLOWED=true` قبل الموافقة. لتوجيه الموقع إلى الوسيط بعد نشره عدل `assets/js/air-config.js` بالرابط الفعلي؛ عند تركه فارغًا يستعمل الموقع المسار المباشر السابق. يوفر الوسيط تحققًا للإحداثيات و CORS للمنشأ المعروف وتخزينًا مؤقتًا 60 ثانية لكل منطقة تقريبية 0.25 درجة.

**حالة الاختبار:** لم يتيسر تأكيد طلب حقيقي من ADS-B أو فتح الموقع من هاتف/حاسوب متصلين بالإنترنت في بيئة التنفيذ. يجب تنفيذ اختبار المتصفح الفعلي بعد السماح بالوصول، والتحقق من رموز HTTP وأعمار الرصد ورسائل الخطأ ومعدلات الطلبات. وجود ملفات الوسيط لا يعني أنه نشط.
